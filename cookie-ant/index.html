FAQ

Questions, answered.

Is Cookie Ant free?

Yes. It's free, with no account, ads or in-app purchases.

Does it upload my cookies anywhere?

No. Everything happens inside your browser. The extension makes no network requests, and the only file it creates is the export you choose to save.

Which browsers does it work in?

Google Chrome, plus Chromium-based browsers that install from the Chrome Web Store, such as Microsoft Edge, Brave and Opera.

Can I share an exported file?

Please don't. Exported cookies can contain active login sessions, so anyone with the file may be able to sign in as you. Keep exports private and delete them when you're done.

Why does it need access to all sites?

Chrome only lets an extension read or write cookies for sites it has access to. You decide which sites to export or import, so it needs access to all of them. It never reads page content or injects scripts.

What file format does it use?

A readable JSON file. Imports also accept plain JSON arrays of cookies from other tools.
